## Project structure and file purpose

### DsnFarms.slnx
- This is the Visual Studio solution file.
- It groups one or more projects so Visual Studio/.NET can open them together.
- In your case it references DsnFarms.csproj.
- It is created automatically when you create a new solution/project in Visual Studio.

### DsnFarms.csproj
- This is the .NET project file for the application.
- It defines:
  - target framework: `net10.0`
  - output type: `Exe` (console application)
  - C# features like `ImplicitUsings` and `Nullable`
- It is required by the SDK to build and restore packages, and to compile your app.

### Program.cs
- This is the main source code file.
- It contains the `Program` class and `Main` method, which is the entry point of the app.
- Your app currently:
  - asks for a product name
  - reads price and quantity
  - calculates total, discounts, GST
  - prints a bill summary

### README.md
- A simple documentation file.
- It describes the project purpose: `.NET + React for the DSN farms`.
- Useful for anyone opening the repo to understand what the project is about.

### `bin/` folder
- Build output directory.
- Contains compiled application files for the chosen configuration (`Debug/net10.0`).
- Includes `DsnFarms.deps.json`, `DsnFarms.runtimeconfig.json`, and the compiled binary.
- Created automatically when you build the project.

### `obj/` folder
- Intermediate build files and caches.
- Contains generated files used by the compiler and build system.
- Also created automatically during build/restore operations.

### Hidden project-related folders
- `.vs/` is a Visual Studio settings folder.
- It stores user-specific IDE data like local debugging settings.
- Not required to build the app, but useful for the Visual Studio environment.

---

## Why these exist

- `*.slnx` and `*.csproj` define the project structure for .NET and Visual Studio.
- Program.cs contains the actual application logic.
- README.md explains the repo to humans.
- `bin/` and `obj/` are generated by the build process to store outputs and temporary build state.
